# NexLabs Technology — Onboarding & Activation

**Status:** `CANONICAL_WO_013`

## Goal

Onboarding should get a user from signup/purchase to first recognized meaningful value with minimum friction.

## Definitions

### Signup
Account/access exists.

### Setup complete
Minimum configuration exists.

### Activation
User/account completes the product-specific behavior that strongly indicates first real value.

### Time-to-value
Time between relevant start point and activation/value event.

## Onboarding design

Prioritize:
- critical setup only;
- progressive disclosure;
- clear next action;
- realistic sample/demo when useful;
- error recovery;
- human/help path for blocked users.

## Activation metric

Must be product-specific and evidence-based.

Examples can include:
- first successful workflow;
- first integrated data source;
- first accepted generated output;
- first completed collaboration.

“Logged in” is usually not activation.

## Onboarding analytics

Track:
- start;
- step completion;
- drop-off;
- activation;
- time-to-value;
- support friction;
- segment differences.

## Commercial handoff

For assisted sales, promised outcomes/use cases should be handed to onboarding/CS so value can be verified rather than forgotten after contract signature.
