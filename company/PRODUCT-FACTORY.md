# NexLabs Technology — Product Factory

**Status:** `CANONICAL_WO_008`

## Canonical flow

`IDEA → INTAKE → RESEARCH → VALIDATION → PORTFOLIO DECISION → SPECIFIED → BUILD → RELEASE → OBSERVE → ITERATE / SCALE / PAUSE / PIVOT / KILL`

A stage transition is a decision, not a label change.

## Stage 1 — IDEA

Output:
- short opportunity statement.

No build authority.

## Stage 2 — INTAKE

Minimum:
- target user;
- problem;
- proposed value;
- why now;
- strategic domain;
- initial monetization hypothesis;
- known risk.

Output:
- Product Intake Record.

## Stage 3 — RESEARCH

Investigate:
- user/problem evidence;
- alternatives/competition;
- demand/search/community signals where relevant;
- distribution paths;
- technical feasibility;
- regulatory/security considerations;
- rough economics/cost drivers.

Output:
- Research/Evidence Pack.

## Stage 4 — VALIDATION

Test the highest-risk assumptions as cheaply as practical.

Possible evidence:
- interviews;
- landing-page demand;
- search/community evidence;
- prototype usage;
- willingness-to-pay;
- competitor gaps;
- technical spike;
- cost benchmark.

Output:
- Validation Decision Pack.

## Stage 5 — PORTFOLIO DECISION

Founder/CEO chooses:
- reject;
- research more;
- validate more;
- admit as Explore;
- admit to product specification/build;
- defer.

AI scoring informs, not replaces, strategic judgment.

## Stage 6 — SPECIFIED

Create sufficient product/engineering definition before build:
- problem/user;
- scope;
- primary value proposition;
- MVP boundary;
- success metrics;
- monetization hypothesis;
- architecture constraints;
- security/risk;
- acceptance criteria.

Output:
- approved Product Case + engineering handoff.

## Stage 7 — BUILD

Engineering runs under GEF:
`Work Order → Context Lock → Execution → Tests/Evidence → Review → Checkpoint`

## Stage 8 — RELEASE

Release only after applicable quality/security/operational gates.

## Stage 9 — OBSERVE

Measure actual behavior:
- activation;
- usage;
- retention;
- revenue/conversion where applicable;
- cost;
- support;
- reliability;
- qualitative feedback.

## Stage 10 — PORTFOLIO ACTION

Choose:
- iterate;
- scale;
- maintain;
- pause;
- pivot;
- kill/retire.

## Factory output

The Product Factory is successful when it reduces the cost of learning **before** expensive build and makes continued investment conditional on evidence.
