## Precedence

For company facts/public claims:
`nexlabs-company canonical sources > website presentation copy`.

For implementation detail:
`website engineering sources > company high-level visual implementation suggestions`, provided they do not contradict brand authority.

## Change synchronization

If the website program needs to change a canonical brand decision:
1. create a governed brand decision in the company repository;
2. approve/promote it;
3. update website implementation under its own GEF process.

If implementation merely refines CSS/token values or technical method while preserving the brand contract, no company-strategy rewrite is required.

## Portfolio synchronization

Public portfolio records should originate from governed product/project evidence.

The website may render/cache them, but it must not strengthen their status.

## No circular authority

Website screenshots are evidence of implementation, not authority to rewrite company facts automatically.

Company documents are authority, not proof that a website feature is already implemented.
