# NexLabs Company v0.1 — Definition of Done

v0.1 is complete only when every release-blocking obligation below is objectively satisfied.

## Governance
- Canonical Source Pack exists and is internally consistent.
- Every executed increment has a stable Work Order, Context Lock, PR, evidence and audit verdict.
- Checkpoint reflects exact accepted Git state.
- No unresolved HIGH/CRITICAL defect exists.

## Company blueprint
- Company identity, business model, authority model and strategic boundaries are approved.
- AI workforce and employee-contract model are approved.
- Product Factory and engineering operating model are approved.
- Security, finance and commercial baseline are approved.

## Technical design
- Company OS functional architecture is approved.
- Local-first infrastructure architecture is approved.
- Agent runtime abstraction and Hermes adapter design are approved.
- High-risk authorization boundaries are implemented or explicitly blocked from execution.

## MVP proof
- A founder-approved software idea can enter the autonomous engineering cell.
- The system produces/uses a governed plan and admitted Work Order.
- Execution produces code or an equivalent controlled artifact through an executor adapter.
- Tests/evidence are captured.
- Review can return APPROVED or CORRECTION REQUIRED.
- Correction remains bound to the same Work Order when safe.
- Checkpoint promotion occurs only after objective audit.

## Operations
- Minimum founder visibility into runs, failures, approvals and project state exists.
- Backup/recovery expectations are documented and tested where stateful components exist.
- No secrets are committed.
- Local environment is reproducible from repository instructions.

## Acceptance
- Final integrated WO-022 audit verifies all NECESSARY obligations.
- Residual risks are documented.
- Founder explicitly accepts v0.1.
